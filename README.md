
# 🤖 Machine Learning (ML) Lab Practicals

This repository contains Python scripts, Jupyter Notebooks, datasets, setup guides, and algorithm implementations for the **Machine Learning Laboratory** course.

---

## 🛠️ Tools & Libraries Installed

* **Programming Language:** Python 3.x
* **Environment & Package Management:** Anaconda Navigator, `venv` / `conda`
* **Development IDE:** Jupyter Notebook / VS Code / Google Colab
* **Core ML Libraries:**
  * `NumPy` & `Pandas` (Data Manipulation & Preprocessing)
  * `Matplotlib` & `Seaborn` (Data Visualization)
  * `Scikit-learn` (Machine Learning Models & Metrics)
  * `TensorFlow` (Deep Learning Foundations)

## 🚀 How to Run Locally

1. **Clone the Repository:**
   ```bash
   git clone [https://github.com/Ammara-cse/Machine-Learning-Lab.git](https://github.com/Ammara-cse/Machine-Learning-Lab.git)
   cd Machine-Learning-Lab



2. **Create and Activate Virtual Environment:**
```bash
# Windows
python -m venv ml_env
ml_env\Scripts\activate

# Linux / macOS
source ml_env/bin/activate

```


3. **Install Dependencies:**
```bash
pip install jupyter notebook numpy pandas matplotlib scikit-learn tensorflow

```


4. **Launch Workspace:**
```bash
jupyter notebook

```
